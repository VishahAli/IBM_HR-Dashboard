HR Analytics Dashboard – Power BI
 Project Overview

This project presents an interactive HR Analytics Dashboard developed using Microsoft Power BI. The dashboard analyzes employee data to provide insights into employee attrition, workforce demographics, salary distribution, job levels, education, and years of service.

The objective of this project is to transform raw HR data into meaningful visual insights that can support data-driven workforce analysis and HR decision-making.

Key Insights

Some observations from the dashboard include:

Research & Development has the highest number of employee attritions among the departments shown.
Employees in the lower salary slabs account for a significant proportion of attrition.
Job Level 1 shows the highest attrition compared with higher job levels.
Attrition varies considerably based on years at the company, providing useful insight into employee retention patterns.
Life Sciences represents the largest education category among employees who left.

 Project Objective

The primary objective was to develop a professional HR dashboard that enables users to:

Monitor employee attrition.
Identify patterns across different employee categories.
Analyze factors associated with employee turnover.
Compare attrition across departments, salary levels, job levels, and education.
Present HR data through an interactive and easy-to-understand interface.
